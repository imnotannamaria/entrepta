# Fonts for the share images

TTF files for `lib/og.tsx`, which renders the Open Graph images at build time. Satori reads TTF,
not woff2, and vendoring the files keeps the build off the network.

- **Newsreader** (regular and italic), by Production Type. SIL Open Font License 1.1.
  https://github.com/productiontype/Newsreader
- **JetBrains Mono** (regular and medium), by JetBrains. SIL Open Font License 1.1.
  https://github.com/JetBrains/JetBrainsMono

Both licenses: https://openfontlicense.org. The fonts are used unmodified.
